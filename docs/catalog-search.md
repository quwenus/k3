# Поиск каталога

Поиск работает локально в браузере по данным `/api/products`. Общая страница — `/catalog/search`; страницы `/catalog/car` и `/catalog/moto` используют ту же логику с фильтром категории. Запрос `q` и порядок `sort` сохраняются в URL.

`src/utils/productSearch.js` строит индекс один раз после загрузки товаров:

- Артикулы и OEM сравниваются без регистра, пробелов и разделителей, с заменой похожих кириллических букв на латинские. Отдельные OEM из списков с запятыми, точками с запятой, табуляцией и переносами не склеиваются.
- Для марок и моделей используется явный словарь русских названий. Известное написание `Daster` сопоставляется с `Duster` только при поиске; исходные данные не переписываются.
- По умолчанию при непустом запросе точный артикул идёт выше точного OEM, затем частичные номера, название и применяемость. Пользователь может выбрать сортировку по номеру.
- Заголовки марок в применяемости связываются со следующими строками моделей. Слова из разных строк применяемости не объединяются в один результат.

Это текстовый поиск, не справочник точного подбора по году и комплектации. Свободный текст в названиях и применяемости сохраняет ограничения исходных данных; диапазоны годов не интерпретируются. Произвольные опечатки автоматически не исправляются.

Проверки: `npm run test:search`, `npm run build`. Для изменения словаря и правил добавляйте примеры в `src/utils/productSearch.test.js`.
